# Golavo v0.18.0 — History beside history

Golavo 0.18.0 adds the two remaining high-confidence items from the verified open-data
roadmap. The World Cup lab now opens with the women's tournament record beside the men's,
and the isolated OpenLigaDB overlay can display the current Frauen-Bundesliga. Both are
reference surfaces: neither changes the deterministic forecasting engine.

## What is new

- **Women-first World Cup archive.** Read eight women's tournaments from 1991–2019,
  then switch to the 22 men's tournaments from 1930–2022. The archive includes titles,
  finals, appearances, each edition's final four, and the individual awards recorded in
  the pinned source.
- **One explicit source boundary.** Archive rows come from the hash-verified Fjelstul
  World Cup Database snapshot at `f942c6b` under CC-BY-SA-4.0. The interface shows its
  source, creator, license, pinned revision, and Golavo's selection/summarization note.
- **Frauen-Bundesliga overlay.** OpenLigaDB Settings now offers the current women's
  competition through the live-verified `ffb1` shortcut. The older `fbl1` identity is
  rejected instead of silently remapped. Advertised future groups whose match endpoint is
  exactly empty may retain an honestly absent revision marker; any non-empty group without
  revision metadata still fails closed.
- **Narrow-screen archive.** Tournament pedigree becomes a labelled mobile card layout,
  while the category control, edition selector, final four, awards, and provenance remain
  keyboard and screen-reader reachable.
- **Season Scenario Composer.** Apply 1–12 unique future results in one ephemeral run and
  compare one selected deterministic voice with the canonical outlook. Drafts survive a
  recoverable engine error; reset returns to the verified outlook; nothing is persisted,
  sealed, or reused as model input.
- **Fixture importance from existing runs.** Each remaining match can show how much a win
  rather than a loss moves each club's title, top-four, and relegation chances. Thin
  conditional branches report `insufficient_coverage` instead of a noisy percentage.
- **Projected points and the run-in.** Every model voice reports projected final points,
  and the league view pairs them with the next five opponents and projected finish band.
- **Source-mode correction discipline.** The web/source app no longer probes authenticated
  correction routes when no desktop token exists, avoiding misleading authorization errors
  without weakening the installed-app boundary.

## Trust boundaries

- Historical archive rows never enter the forecast index, model training, calibration,
  an outlook, AI numeric authority, or a sealed artifact.
- The Fjelstul archive carries the required `© 2022 Joshua C. Fjelstul, Ph.D.` notice,
  source and license links, pinned revision, and Golavo modification note. Official frozen
  builds sign its isolated-pack manifest with the same identity used for active core packs.
- OpenLigaDB remains opt-in, ODbL-attributed, per-user, separately stored, removable,
  display-only, and structurally excluded from CC0 packs, training, forecasts,
  settlement, calibration, and redistributable exports.
- Installers remain OS-unsigned and not notarized, so Gatekeeper or SmartScreen may warn
  on first install. Updater payloads, active official pack manifests, and the aggregate
  checksum ledger retain Golavo's existing signed release identity.
